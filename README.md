## Project Overview

This portfolio demonstrates how generative AI can support a **Business Analyst** in completing common workplace tasks more efficiently and consistently.

The examples cover prompt engineering, professional writing, information processing, planning, verification, responsible AI use, and personal AI integration. All examples are connected to one fictional employee service request improvement scenario and were reviewed by the trainee.

---

## Selected Workplace Scenario

The selected role is **Business Analyst**, supporting a fictional project to improve an internal employee service request process.

The scenario involves:

- analysing stakeholder requirements;
- documenting and improving business processes;
- summarising stakeholder meetings;
- prioritising requirements;
- preparing professional stakeholder communication;
- identifying risks, dependencies, and open questions; and
- verifying AI-assisted outputs before they are used.

---

## Course Skills Demonstrated

- Structured prompting using **C.A.R.E.** and **R.C.T.O.**
- Creating reusable prompts for Business Analysis tasks
- Professional writing using **Draft → Verify → Refine → Human Sign-off**
- Summarising, extracting, restructuring, and prioritising information
- Planning using **Goal → Mechanisms → Phases → Tasks**
- Verifying AI-generated content against original sources
- Applying responsible AI and information-sensitivity controls
- Developing a practical personal AI integration plan

## Key Learnings

1. Clear and structured prompts produce more useful and consistent AI outputs.
2. AI-generated information must be verified against the original source before use.
3. Missing information should be clearly marked as `[Not Specified]` rather than guessed.
4. Responsible AI use requires attention to privacy, confidentiality, bias, and human oversight.
5. AI can support Business Analysis tasks, but final judgement and accountability remain with the human user.
